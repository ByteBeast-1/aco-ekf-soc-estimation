1. Current state (facts found in the repo)

advanced_bms_aco_ekf.slx: simulated 2-RC Arrhenius plant (Battery_Physics_Plant), seeded faultable sensors (Sensor_Measurement), one estimator (ACO_EKF_Controller, mode 0), 8 scopes. Init: bms_setup('synthetic').

sota_bms_aco_ekf.slx: replays real NASA B0005/6/7 data (NASA_Replay) through three estimators side by side: EKF_Baseline (mode 0), SOTA_Adaptive_Controller (mode 2, Sage-Husa R) and SOH_Capacity_Estimator (mode 10, capacity state plus Sage-Husa R). Init: bms_setup('nasa').

Both call lib/bms_est_step.m. It is a 4-state Joseph-form EKF with states [SOC, V1, V2, capacity ratio]; the capacity state is frozen unless mode bit 8 is set. Mode bits: 1 = RLS on R0, 2 = Sage-Husa R, 4 = Sage-Husa Q, 8 = capacity state.

ACO: lib/bms_aco_tune.m (ACO_R, 4 log-parameters: Q_soc, Q_v1, Q_v2, R) writes lib/bms_tuned_data.m. Tuning data is disjoint from evaluation data.

C twin: c_firmware/bms_ekf.c/.h, mode 0 only, float32, 236 bytes of state. Software-in-the-loop (SIL) check exists in lib/bms_sil_run.m.

Known real-data results (from results/bms_regression_results.csv): fresh NASA cells MAE 0.66 % and 0.93 %; aged cells 2.3 to 4.9 %; Coulomb counting 6 to 12 %.

3. Phase 2: Connect the two Simulink models (the main request)

Goal: one model family that can run any input source through any estimator set, with the same metrics code. Implement options A to D below; A and B are mandatory.

A. Common scenario and metrics layer (MATLAB, no Simulink change needed)

Create simulink_matlab/bms_scenario.m: returns a struct with fields name, source ('synthetic'|'nasa'), I, V_ref, T, soc_ref, soc0, init_err, seed, fault_mode, params_variant.

Create simulink_matlab/run_all.m: loops over a scenario list, runs both models (via Simulink.SimulationInput for sweeps), collects bms_log, calls lib/bms_metrics.m, and writes one CSV plus one comparison figure per scenario into results/.

Add regression suite 8: the unified run must reproduce the existing per-model results within 1e-9.

B. Unified model bms_unified.slx (generated by build_bms_models.m)

Input source as a Variant Subsystem, selected by workspace variable BMS_Source: SIM (plant plus sensors, from advanced model) or REPLAY (NASA data, from sota model).

Estimator bank as a Variant Subsystem or an enabled set of three referenced estimators: EKF (mode 0), ADAPTIVE (mode 2), SOH (mode 10). Selected by BMS_EstimatorSet.

Wrap the estimator as a referenced model bms_estimator_ref.slx so both legacy models and the unified model use the same block. Keep the old advanced_bms_aco_ekf.slx and sota_bms_aco_ekf.slx generated from the same builder, so nothing existing breaks.

Common sensors: allow the REPLAY source to pass through Sensor_Measurement with fault injection too (flag BMS_InjectFaultsOnReplay), so real data can be tested under faults.

Keep the bus objects and bms_data.sldd as the shared interface. Add a BMS_Reference bus (soc_ref, source tag) so the SIM and REPLAY sources expose the same reference signal.

4. Phase 3: Strengthen the science

Prove the ACO contribution. Add lib/bms_tune_compare.m comparing, at the same evaluation budget (same number of fitness calls, many seeds): hand-tuned, random search, grid search, Nelder-Mead or fminsearch, particle swarm or genetic algorithm (MATLAB ga/particleswarm if available), and ACO_R. Report mean and spread of final fitness and of held-out MAE. If ACO does not win, say so; document the real finding.

Reproduce one published baseline (for example the base paper's ACO-EKF as described, plus a standard adaptive EKF such as AEKF with innovation-based covariance matching) before using the word "SOTA". Cite the source in the doc.

Multi-objective properly. The tuner currently scalarises MSE plus lambda times convergence time. Add a true Pareto front (NSGA-II style or MO-ACO with archive) and plot MSE vs convergence time; keep the scalar result as a default.

Fix the OCV model. The synthetic polynomial reaches 4.59 V at 100 % SOC. Replace with a monotonic lookup table (griddedInterpolant/interp1 friendly, codegen-safe) calibrated per chemistry, with SOC range 0 to 1 mapping to 3.0 to 4.2 V for the NMC/NCA cells. Keep the old polynomial selectable as legacy.

Aging and SOH. Improve capacity tracking: joint capacity and R0 estimation with sufficient excitation gating, or a dual-EKF (fast SOC filter, slow parameter filter). Report capacity-ratio error versus cycle number on all 3 NASA cells. Document the observability limit of one constant-current discharge.

Detect the silent fault. Current-sensor offset raises max error from 0.40 % to 0.75 % without any flag. Add an offset detector (for example Coulomb-vs-voltage drift monitor at rest, or an extended state for current bias), with a detection flag bit 32.

Observability and consistency checks. Add NEES and NIS whiteness tests (autocorrelation of innovation) as automated pass/fail criteria in the regression.

Temperature. Test at 0, 10, 25, 40 degrees C. Add Arrhenius parameter identification from data instead of the fixed Ea of 18000 J/mol.

Statistics. Report mean, standard deviation, 95th percentile and max error over at least 100 Monte Carlo runs, with confidence intervals.

5. Phase 4: Real and dynamic data

The biggest industry gap is that NASA data is a constant 2 A room-temperature discharge.

Add loaders (lib/bms_load_<dataset>.m and Python equivalents) for at least one dynamic dataset: CALCE (INR 18650-20R / A123 with DST, FUDS, US06), Oxford Battery Degradation, Panasonic 18650PF (McMaster, with temperatures from -20 to 25 degrees C), or Samsung 30Q. Put download scripts in data/download_*.py, never commit large raw data; add checksums.

Calibrate a separate cell parameter set per dataset (OCV from low-rate test, RC from pulse or ID script). Hold out whole cells and whole cycles for validation.

Add scenarios: DST/FUDS/US06/UDDS/WLTP, low-temperature, aged cell, wrong initial SOC (plus and minus 20 %), sensor dropout.

Update the results table with a "dynamic data" section.

6. Phase 5: Real BMS functions (system level)

Protection and fault state machine (Stateflow, generated by the builder): states NORMAL, WARNING, DERATE, FAULT, SHUTDOWN. Inputs: voltage, current, temperature, estimator fault code, NIS flag. Define thresholds in bms_params. Add hysteresis and debounce timers.

State of Power (SOP) estimate: maximum charge and discharge current limits from voltage and SOC limits using the 2-RC model.

Pack model: series string (for example 4 to 96 cells), cell-to-cell spread in capacity, R0 and initial SOC, with per-cell estimators and a pack SOC definition.

Cell balancing: passive balancing logic (bleed resistor model, voltage-threshold and SOC-based strategies) and optionally active balancing; metrics: time to balance, energy lost.

Thermal model: lumped cell thermal model (heat from I^2 R, convection), coupled to the Arrhenius parameters. Feed estimated temperature, not only measured.

Charging control: CC-CV charging with SOC-based termination and temperature derating.
