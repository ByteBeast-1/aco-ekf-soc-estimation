# data/

| File | What it is |
|---|---|
| `SYNTHETIC_B0005.csv` | **Synthetic** 2 A discharge generated by `python/nasa_dataset_loader.py` from an analytic formula (the download fell back to the generator). It is NOT measured NASA data. Used by `python/nasa_benchmark_runner.py` and `python/main_ultimate.py`. |
| `NASA_B0005_OFFICIAL_Cycle1.csv` | Real measured discharge cycle #1 of NASA cell B0005, extracted from `data_raw/B0005.mat` by `python/parse_official_nasa_mat.py` (about 18 s sampling). |

Real measured data for the MATLAB/Simulink work is read straight from `../data_raw/B000x.mat`
(`simulink_matlab/lib/bms_nasa_load.m`).
